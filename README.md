# TIGER WEB

موقع ثابت جاهز لـ GitHub Pages.

## الملفات
- index.html
- style.css
- script.js

## التشغيل على GitHub Pages
1. ارفع الملفات الثلاثة إلى Repository.
2. Settings -> Pages.
3. اختر Deploy from a branch.
4. اختر main و / (root).
5. Save.

الموقع يحتوي على:
- TIGER WEB في الصفحة الرئيسية.
- قائمة جانبية بثلاث شرطات.
- 3 ألعاب: Snake و Tic Tac Toe و Click Rush.
- قسم Apps.
- إعدادات لون الخلفية ولون الواجهة واللغة العربية/English.
- حفظ الإعدادات في المتصفح.
- حقوق النشر: TIGER-dev-2026.
